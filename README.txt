저장소에 올릴 파일 6개입니다. 파일명의 __ 는 폴더 구분입니다.

1_package.json                              →  package.json
2_scripts__build-blog.mjs                   →  scripts/build-blog.mjs
3_scripts__render.mjs                       →  scripts/render.mjs
4_scripts__fixture.json                     →  scripts/fixture.json
5_github__workflows__daily-rebuild.yml      →  .github/workflows/daily-rebuild.yml
6_gitignore.txt                             →  .gitignore

깃허브 웹에서: Add file → Create new file → 이름 칸에 오른쪽 경로를 그대로 입력
(경로에 / 를 치면 폴더가 자동 생성됩니다) → 내용 붙여넣기 → Commit.
